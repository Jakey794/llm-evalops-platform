# Security policy

## Supported versions

Security fixes are applied to the current `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not include exploit details, secrets, or personally identifiable information in a public issue.

This project is a reference implementation. Before exposing it to untrusted users or connecting it to real data, add authentication, authorization, rate limits, audit logging, secret management, and a threat-model review.
